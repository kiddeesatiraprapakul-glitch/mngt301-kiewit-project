# Crew Ready: MNGT 301 Kiewit Project

Sample website for our MNGT 301 group project at the University of Nebraska-Lincoln. It looks at how labor shortages and gaps in equipment knowledge affect construction workers, using Kiewit as an example company.

This is a student proposal. It is not affiliated with or endorsed by Kiewit.

## Pages
- `index.html`: home page (the gaps, solutions, equipment, skills checklist, who to contact, research)
- `training/`: excavators, cranes and rigging, aerial and scissor lifts, OSHA training
